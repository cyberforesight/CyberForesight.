# Core Model

Primary World Model: LSTM, learning P(S_t+1 | S_t) over time-windowed states, not per-flow classification. Baseline: Logistic Regression. Implementation is a practical, supervised approximation of state-transition/progression prediction — not a full causal simulator.

# Data

Primary dataset: CIC-IDS2018. Potential future datasets: CIC-IDS2017, UNSW-NB15, CTU-13, CICIoT2023, other compatible public sets. Important fact: CSV flow data may not contain all packet-level features. Packet-derived features are only used when actually extracted from packet data — never fabricated.

Flow features: source/destination IP & port, protocol, TCP flags, bytes, packets, flow duration, IAT statistics, bidirectional ratios. Packet-derived features: TTL & variance, TCP window size, fragmentation, payload statistics, port scan patterns, retransmission counts.

# Temporal Representation

Traffic aggregated into configurable time windows (e.g., W1 = 09:00–09:01 ). Each window → one network state vector S_t.

# Forecasting

K-step forward simulation producing: infiltration probability timeline, future risk, predicted attack stage, probable attack paths, path probability, lead time, contributing features.

# Attack Stages

Reconnaissance · Initial Access · Lateral Movement · Command & Control · Exfiltration.

# Attack Paths

Represented as sequences, e.g. PC → File Server → Database. Multiple probable paths supported and ranked.

# Asset Risk

Based only on available network evidence/configuration. Criticality values are never invented.

# What-If Simulation

Supported simulated interventions: Restrict SMB, Isolate Host. Hypothetical only — simulator modifies a copy of state and reruns the forecast; the real network is never changed.

# Dashboard

Framework: Streamlit. Concept name: "Zero-Hour Foresight" / Network Forecasting SOC. Views: current risk, forecast, attack paths, MITRE stage, SHAP explanation, asset risk, attack timeline, attack graph, what-if simulation, before/after forecast, defence recommendation, benchmark.

# Offline

Core system must run offline. No mandatory cloud APIs. LLM functionality is optional.

# Terminology

World Model: a learned model of how network states evolve over time. Network State: a time-windowed representation of network behaviour. State Transition: movement from S_t to S_t+1.

K-step Forecast: rolling prediction several time windows into the future. Attack Path: a sequence of network/attack progression states. Lead Time: how early the system forecasts an event before it is observed. Probability: model-estimated likelihood. Confidence: a separate calibration/certainty measure, if implemented. Observed: based on actual telemetry. Predicted: generated by the model. Simulated: produced by a hypothetical intervention.

# Current Implementation Principles

Python-first · modular · offline-first · LSTM-first · explainability-first · reproducible · defensive · minimal unnecessary complexity.

# Do Not Assume

Do not assume packet-level features exist unless verified. Do not assume all attack stages are directly labelled in the dataset. Do not assume an LLM is available. Do not assume real-time deployment data exists.
